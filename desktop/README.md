# Desktop configuration

This stow package provides the Hyprland Lua configuration, UWSM session environment, Waybar, SwayNC, and the CopyQ XDG autostart entry. UWSM activates XDG autostart entries through systemd and starts `graphical-session.target`; Waybar and SwayNC therefore use their packaged user services instead of Hyprland autostart commands. Their drop-ins place them in UWSM's application slice for clean session shutdown.

On a fresh machine, save the autogenerated Hyprland configuration, then run the desktop installer:

```sh
mv ~/.config/hypr ~/.config/hypr.before-dotfiles
./setup_desktop.sh
```

Pass `--with-greetd` to also install the root-owned Greetd configuration and enable its system service. This does not start Greetd immediately; reboot after the command. The script intentionally does not install an NVIDIA driver because that choice depends on the machine and kernel. Log out and select the `Hyprland (uwsm)` session, then log in again.

The UWSM environment files carry the NVIDIA and toolkit variables. No legacy NVIDIA workarounds are enabled; add an `AQ_*` workaround only when a specific observed issue requires it.

`greetd/config.toml` is the system-level Greetd template. It starts Tuigreet on TTY1, defaults to the UWSM-managed Hyprland session, and retains Tuigreet's session chooser.

After installing `hyprpolkitagent`, enable its packaged user service with `systemctl --user enable --now hyprpolkitagent.service`. `nm-applet` is started by UWSM through the XDG autostart entry.
